### 2. Задание 1 — отсутствует метод модального управления (каноническая форма)
Требуемые три метода синтеза K:
- Уравнение Сильвестра ✓
- **Метод модального управления** (перевод в каноническую управляемую форму) — ОТСУТСТВУЕТ
- Формула Аккермана или Басс-Гура ✓

Используются Аккерман + Басс-Гура + Сильвестр — два аналитических метода вместо одного,
при этом метод канонической формы пропущен.

Эталон (стр. 5–7) показывает метод подробно:
1. Жорданова декомпозиция системы
2. Удаление неуправляемой части → уменьшенная система (A*, B*)
3. Перевод (A*, B*) в каноническую управляемую форму
4. Нахождение K_упр из условия A_упр + B_упр·K_упр = Γ
5. Обратное преобразование к исходному базису

**Действие:** заменить один из методов Аккерман/Басс-Гура на метод канонической управляемой формы.

### 3. Задание 2 — пропущена матрица L₂ и графики для спектра II
Задание требует синтез L "для каждого из спектров".
Эталон показывает явное числовое значение L₂ (с огромными элементами ~10⁸)
и строит графики x(t), x̂(t), e(t) для спектра II ({−7, −70, −700, −7000}).
В текущей работе спектр II только упоминается словесно.

**Действие:** добавить явное значение матрицы L₂ и графики моделирования для этого спектра.

Касается Заданий 2, 3, 4. Знак обратный по всей работе.

**Действие:** исправить определение ошибки и подписи осей на графиках.
